**Lantern Thief** — a top-down stealth game set in a night museum. Slip past three lantern-carrying guards whose vision cones sweep the galleries, use crates and pillars as cover, hold Shift to sneak (a sneaking thief is seen at barely half the range), and click to throw one of three pebbles and pull a guard off his patrol. The alarm fills while a guard sees you and cools when you break his sight; three full alarms end the night. Take all three gems, then reach the EXIT unseen. Plain static files under `game/` — no build step, no network, just open it in a browser.

## Run it

```sh
python3 -m http.server 8080 --directory game   # then open http://localhost:8080
# hand-in check:  mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
